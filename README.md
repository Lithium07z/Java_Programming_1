## 실행 방법

`javac`와 `java`를 사용할 수 있는 JDK가 필요합니다. JDK 버전이나 Maven·Gradle 설정은 저장소에 고정되어 있지 않습니다.

다음은 저장소 루트에서 첫 출력 예제를 실행하는 명령입니다. Windows PowerShell 기준이며, 해당 원본 소스의 CP949 인코딩을 `MS949`로 지정합니다.

```powershell
cd "2주차/firstJavaProject"
javac -encoding MS949 -d out src/HelloJava.java
java -cp out HelloJava
```

실행하면 `HelloJava!`가 출력됩니다. 다른 예제도 해당 폴더에서 필요한 소스를 컴파일하고 `main` 메서드가 있는 클래스를 실행하면 됩니다.

IDE에서는 과제별 Java 프로젝트를 만들고 해당 `src`를 소스 폴더로 지정하세요. `package myclass.lang;`처럼 패키지가 선언된 예제는 패키지 구조를 유지하고 `myclass.lang.MyStringTest`처럼 전체 클래스 이름으로 실행합니다.

## 참고

- 서로 다른 과제에 같은 클래스 이름이 있으므로 모든 `src`를 하나의 프로젝트에 합치지 마세요.
- 한글이 깨지거나 인코딩 오류가 나면 해당 파일의 인코딩과 컴파일 옵션을 맞추세요.
- 수업 당시의 풀이를 보존한 학습 자료입니다. 예제별 입력 조건과 구현을 확인하며 실행할 수 있도록 구성되어 있으며, 통합 빌드와 자동 테스트는 제공하지 않습니다.
